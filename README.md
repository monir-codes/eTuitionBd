## 📌 Overview
eTuitionBD connects students and tutors with smart filtering, authentication, and secure system flow.

---

## ⚙️ Tech Stack
- React (Vite)
- Node.js
- Express.js
- MongoDB
- Firebase Auth
- Stripe API
- Framer Motion

---

## ✨ Features
- Role-based authentication
- Tuition matching system
- Secure login system
- Payment integration (Stripe)
- Dashboard system
- Responsive UI
